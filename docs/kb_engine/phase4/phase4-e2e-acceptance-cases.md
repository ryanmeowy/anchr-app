# Phase4 端到端验收用例

## 1. 固定测试资料

建议准备以下资料，文件名固定，便于复现：

| 文件 | 关键内容 |
|---|---|
| `contract-payment.pdf` | “甲方应在验收合格后30日内完成付款。” |
| `product-manual.docx` | “智能检索支持文本、图片和表格资料。” |
| `price-table.xlsx` | sheet `报价`，表头 `产品/价格/有效期` |
| `faq.md` | “账号 token 过期后需要重新登录。” |
| `ocr-sample.jpg` | 图片内包含 “设备编号 SV-2026-001” |
| `slides.pptx` | 第 2 页包含 “部署步骤分为三步。” |
| `archive.zip` | 包含一个 DOCX、一个 CSV、一个不支持文件 |

## 2. 验收用例

| ID | Query | 资料 | 预期 |
|---|---|---|---|
| E2E-01 | 付款期限是什么？ | PDF | 答案引用 PDF 片段，预览可定位页码 |
| E2E-02 | 验收合格后多久付款？ | PDF | 命中“30日内完成付款” |
| E2E-03 | 智能检索支持哪些资料？ | DOCX | 命中 heading/段落来源 |
| E2E-04 | 报价表里有哪些产品？ | XLSX | 返回 sheet 和行列来源 |
| E2E-05 | token 过期怎么办？ | MD | 命中 Markdown 文本片段 |
| E2E-06 | 设备编号是多少？ | IMAGE | 命中 OCR 文本，bbox 有效时可绘制 |
| E2E-07 | 部署步骤分几步？ | PPTX | 命中 slide 2 |
| E2E-08 | ZIP 里 CSV 的内容是什么？ | ZIP | ZIP 内支持文件可检索 |
| E2E-09 | ZIP 里不支持文件如何处理？ | ZIP | 任务 item 或解析内容显示跳过原因 |
| E2E-10 | 只在当前知识库搜索付款期限 | 两个 KB | 不命中未选 KB |
| E2E-11 | 搜索结果生成答案 | PDF/DOCX | 搜索列表和答案可同时展示 |
| E2E-12 | 多轮追问“那依据是哪一条？” | PDF | 回答引用上一轮相关证据 |
| E2E-13 | 打开第一条引用 | 任意 | 预览接口返回 segment 和上下文 |
| E2E-14 | 刷新过期预览 | 任意 | refresh 后可重新获取 previewUrl |
| E2E-15 | VIEWER 删除文档 | 任意 | 返回 403，前端展示权限不足 |
