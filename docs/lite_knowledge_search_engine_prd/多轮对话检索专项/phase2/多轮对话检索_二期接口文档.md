# 多轮对话检索专项（二期）接口文档

更新时间：2026-05-07  
状态：Draft for Execution  
依据：`多轮对话检索_二期PRD.md`

## 1. 通用约定

### 1.1 Base Path

```text
/api
```

### 1.2 认证

二期不引入完整 SSO，沿用当前项目轻量 token 机制。

请求头：

```http
X-Access-Token: <token>
```

要求：
1. 预览接口必须校验 token 后才签发 `previewUrl`。
2. token 不允许写入日志。
3. 本期不实现多用户会话隔离，conversation 会话统一归属 `single_user`。
4. 未来接入 SSO 后，由认证上下文提供真实 `userId`，接口结构不变。

### 1.3 通用响应

沿用项目通用 `Result<T>` 包装。

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

错误响应示例：

```json
{
  "code": 401,
  "message": "The token is invalid or expired",
  "data": null
}
```

### 1.4 通用错误码

| HTTP | code | 场景 |
|---:|---:|---|
| 400 | 400 | 请求参数错误 |
| 401 | 401 | token 缺失、无效或过期 |
| 403 | 403 | 无权限访问会话、segment 或 asset |
| 404 | 404 | session、turn、segment 或 asset 不存在 |
| 429 | 429 | 请求过快，可用于预览签发限流 |
| 500 | 500 | 服务端异常 |

## 2. 会话接口

### 2.1 创建会话

```http
POST /api/conversations
Content-Type: application/json
X-Access-Token: <token>
```

请求：

```json
{
  "title": "合同付款条款"
}
```

字段说明：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `title` | string | 否 | 会话标题；为空时后端生成默认标题 |

响应：

```json
{
  "sessionId": "conv_123",
  "userId": "tk_ab12cd34",
  "title": "合同付款条款",
  "status": "ACTIVE",
  "createdAt": 1714665600000,
  "updatedAt": 1714665600000,
  "expiresAt": 1717257600000
}
```

说明：
1. `userId` 本期固定为 `single_user`，仅作为未来 SSO 接入的兼容字段。
2. `expiresAt` 表示 Redis 会话 TTL 到期时间，二期只承诺 TTL 内恢复。

### 2.2 获取会话详情

```http
GET /api/conversations/{sessionId}
X-Access-Token: <token>
```

响应：同 `ConversationSessionDTO`。

### 2.3 获取会话历史列表

```http
GET /api/conversations?limit=20&cursor=<cursor>
X-Access-Token: <token>
```

查询参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `limit` | integer | 否 | 20 | 返回数量，建议上限 50 |
| `cursor` | string | 否 | - | 游标，用于翻页 |

响应：

```json
{
  "items": [
    {
      "sessionId": "conv_123",
      "userId": "single_user",
      "title": "合同付款条款",
      "status": "ACTIVE",
      "createdAt": 1714665600000,
      "updatedAt": 1714665900000,
      "lastMessagePreview": "付款应在验收后30日内完成...",
      "expiresAt": 1717257600000
    }
  ],
  "nextCursor": "eyJ1cGRhdGVkQXQiOjE3MTQ2NjU5MDAwMDB9"
}
```

规则：
1. 本期返回 `single_user` 会话空间内的会话。
2. 按 `updatedAt desc` 排序。
3. 前端可以本地缓存，但不能将本地缓存作为唯一历史来源。
4. Redis TTL 过期后的会话不承诺恢复。

### 2.4 获取会话消息

```http
GET /api/conversations/{sessionId}/messages?limit=20&beforeTurnId=<turnId>
X-Access-Token: <token>
```

查询参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|---|---|---|---|---|
| `limit` | integer | 否 | 20 | 返回 turn 数量 |
| `beforeTurnId` | string | 否 | - | 加载指定 turn 之前的历史 |

响应：

```json
{
  "sessionId": "conv_123",
  "turns": [
    {
      "turnId": "turn_001",
      "sessionId": "conv_123",
      "query": "合同里付款期限是什么？",
      "rewrittenQuery": "合同 付款期限 验收后 付款",
      "answer": "结论：合同约定付款应在验收后30日内完成...",
      "citations": [],
      "resultCards": [],
      "retrievalTrace": null,
      "suggestedQuestions": [],
      "createdAt": 1714665900000
    }
  ],
  "nextBeforeTurnId": "turn_001"
}
```

要求：
1. 历史消息必须从 `ConversationTurn.resultCardsJson` 读取 `resultCards`。
2. 历史回放禁止为了生成卡片发起二次检索。
3. 历史 turn 没有 `resultCardsJson` 时，返回空数组或兼容缺省值。

### 2.5 发送消息

```http
POST /api/conversations/{sessionId}/messages
Content-Type: application/json
X-Access-Token: <token>
```

请求：

```json
{
  "query": "合同里付款期限是什么？",
  "topK": 20,
  "limit": 10,
  "strategy": "HYBRID"
}
```

字段说明：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `query` | string | 是 | 用户原始问题 |
| `topK` | integer | 否 | 检索候选规模 |
| `limit` | integer | 否 | 返回/重排限制 |
| `strategy` | string | 否 | 检索策略，例如 `HYBRID` |

5. `score` 固定取 `primaryHit.score`，本期不做同 asset 多命中加权。
6. `additionalHits` 默认最多返回 2 条。

### 2.6 重命名会话（P1）

```http
PATCH /api/conversations/{sessionId}
Content-Type: application/json
X-Access-Token: <token>
```

请求：

```json
{
  "title": "付款条款分析"
}
```

响应：`ConversationSessionDTO`。

### 2.7 删除或归档会话（P1）

```http
DELETE /api/conversations/{sessionId}
X-Access-Token: <token>
```

响应：

```json
{
  "deleted": true
}
```

说明：
1. 二期可逻辑删除，也可物理删除 Redis key。
2. 删除后会话不应出现在列表中。

## 3. 预览接口

### 3.1 获取 segment 预览信息

```http
GET /api/v1/preview/segments/{segmentId}
X-Access-Token: <token>
```

路径参数：

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `segmentId` | string | 是 | 命中 segment ID，通常来自 `resultCards[].primaryHit.segmentId` |

响应：

```json
{
  "assetId": "asset_001",
  "assetType": "PDF",
  "fileName": "合同.pdf",
  "previewType": "PDF",
  "previewUrl": "https://oss.example.com/xxx?Expires=...",
  "expiresAt": 1714666800000,
  "anchor": {
    "pageNo": 3,
    "chunkOrder": 12,
    "bbox": null,
    "imageWidth": null,
    "imageHeight": null
  },
  "snippet": "甲方应在验收合格后30日内完成付款。",
  "surroundingChunks": [
    {
      "segmentId": "asset_001:3:11",
      "chunkOrder": 11,
      "pageNo": 3,
      "content": "前一个 chunk 内容...",
      "relation": "previous"
    },
    {
      "segmentId": "asset_001:3:12",
      "chunkOrder": 12,
      "pageNo": 3,
      "content": "甲方应在验收合格后30日内完成付款。",
      "relation": "current"
    },
    {
      "segmentId": "asset_001:3:13",
      "chunkOrder": 13,
      "pageNo": 3,
      "content": "后一个 chunk 内容...",
      "relation": "next"
    }
  ]
}
```

要求：
1. 接口必须校验 `X-Access-Token`。
2. 通过 `segmentId` 查询稳定索引或持久化元数据，不依赖入库任务短 TTL 缓存。
3. 默认 `surroundingChunks` 查询窗口为 `current +/- 1`。
4. 单个 chunk 内容默认截断到 2KB-4KB。
5. 无相邻 chunk 时只返回 `current`。
6. 签名 URL 默认有效期 5-15 分钟。
7. 同一 `segmentId + tokenHash` 在有效期内应复用 preview response。

previewType 推断规则：
1. 优先从 `sourceRef/title` 解析文件扩展名。
2. `.pdf` 返回 `PDF`，`.txt` 返回 `TXT`，`.md/.markdown` 返回 `MD`。
3. `.png/.jpg/.jpeg/.webp/.gif/.bmp` 返回 `IMAGE`。
4. 扩展名不可识别时，`assetType=IMAGE` 返回 `IMAGE`，文本资源兜底返回 `TXT`。

错误边界：
1. `X-Access-Token` 缺失或无效返回 `401`。
2. `segmentId` 为空返回 `400`。
3. segment 不存在返回 `404`。
4. preview URL 签发失败返回 `500 / Failed to sign preview URL`。
5. 本期固定 `single_user`，不做 asset 级 ACL；未来接入 SSO 后，无权限访问 segment 或 asset 返回 `403`。

anchor 字段说明：

| 字段 | 类型 | 说明 |
|---|---|---|
| `anchor.pageNo` | integer | PDF 页码或文本类资源页码；从 1 开始 |
| `anchor.chunkOrder` | integer | TXT/MD 或已切 chunk 文本的 chunk 序号；从 0 开始 |
| `anchor.bbox` | object | 图片 OCR 命中框，结构为 `x/y/width/height/unit` |
| `anchor.bbox.unit` | string | 固定为 `PIXEL` |
| `anchor.imageWidth` | integer | 原图宽度，用于 bbox 映射 |
| `anchor.imageHeight` | integer | 原图高度，用于 bbox 映射 |

anchor 降级规则：
1. `anchor` 为 `null` 时，只打开资源，不做命中定位。
2. `PDF` 的 `pageNo` 缺失或无效时打开首页并展示 snippet。
3. `TXT/MD` 的 `chunkOrder` 缺失或无效时优先 snippet 匹配，失败展示 current chunk。
4. `IMAGE` 的 bbox、imageWidth、imageHeight 任一缺失或无效时展示原图和 OCR/命中文本，不绘制命中框。
5. 后端不得用 `0` 或空对象伪造可定位 anchor。

### 3.2 预览 URL 去重策略

前端：
1. 同一 `segmentId` 连续点击只发起一次请求。
2. `expiresAt` 未过期前复用已有 preview response。
3. `401/403/previewUrl` 过期时自动刷新一次，仍失败则提示用户。

后端：

```text
cacheKey = preview:segment:{segmentId}:token:{tokenHash}
cacheTtl = previewUrlRemainingTtl - 30s
```

说明：
1. `tokenHash` 使用 SHA-256 生成，不可逆，不能直接记录原始 token。
2. 如果 URL 已接近过期，应重新签发。
3. 如果安全要求提高，可切换后端代理，不直接返回 OSS URL。

### 3.3 签名 URL 泄露处理

直接 OSS 签名 URL 一旦泄露，后端通常无法中途撤销单个 URL。

二期措施：
1. 签发前校验 token。
2. 使用短 TTL。
3. 不在日志中打印完整 `previewUrl`。
4. 不在前端持久化保存 `previewUrl`。
5. 高安全场景切换后端受控代理/内容 API。

## 4. 反馈接口（P1）

### 4.1 提交回答反馈

```http
POST /api/conversations/{sessionId}/turns/{turnId}/feedback
Content-Type: application/json
X-Access-Token: <token>
```

请求：

```json
{
  "rating": "UP",
  "reason": "回答准确",
  "comment": "可选补充说明"
}
```

字段说明：

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `rating` | string | 是 | `UP` 或 `DOWN` |
| `reason` | string | 否 | 预设或自由文本原因 |
| `comment` | string | 否 | 备注 |

响应：

```json
{
  "feedbackId": "fb_001",
  "sessionId": "conv_123",
  "turnId": "turn_002",
  "rating": "UP",
  "createdAt": 1714666000000
}
```

## 5. 开发者模式

开发者模式默认关闭，不新增独立 API。

前端行为：
1. 关闭时隐藏 `retrievalTrace`、rewrite、preferredModalities、fallback 信息。
2. 开启时展示响应中的 `retrievalTrace`。
3. `preferredModalities` 二期不作为新增能力，只作为 trace/debug 信息展示。
